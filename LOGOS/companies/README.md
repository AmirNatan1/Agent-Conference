# Company logos for the three moving belts

Each belt card loads `LOGOS/companies/<slug>.png`. If the file is absent the card falls back
to the company name set as a wordmark, so the belts work with any subset present.

Tiles are light (#EFEDE6), so dark or full-colour logos both read well.
PNG with transparency preferred, roughly 400x160, generous padding trimmed.

Belt 1: maman, archive2000, globus, tal-limousine, logisticare, laufer, movilit,
        engineering-projects, earthmoving, emi
Belt 2: uti, tashtit, yozma-galilee, hanegev-arava, west-galilee, emek-hayarden,
        tifzoret, taavura-tours, shmerling, venta
Belt 3: ganei-hadas, grandauto, medone, tikshoov, seeu, ups, h-o, refinery, gadiv, caol
