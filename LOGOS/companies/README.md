# Company logos

This directory contains the 29 company marks used by the website's three moving
logo belts. The files intentionally retain their most suitable public format
(PNG, JPG or SVG). Each card links to the company's website and flips on hover
or keyboard focus to show its short profile.

The page duplicates each ten-company sequence at runtime to create a seamless
loop while keeping the source markup accessible and maintainable.
