# Company logos

This directory contains the individual company marks used by the website's
three moving logo belts. Shared parent-brand marks for Hyundai and VDL companies
live one level above this directory. Each card links to the company's website
and flips on hover or keyboard focus to show its short profile.

The page duplicates each company sequence at runtime to create a seamless loop
while keeping the source markup accessible and maintainable.
